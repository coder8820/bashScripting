# 📂 Professional Bash File Organizer

A Bash automation tool that organizes files into categorized
directories based on their file extensions.

## ✨ Features

- Custom directory support
- Dry-run mode
- Duplicate file handling
- Automatic folder creation
- File categorization
- Logging
- Summary report
- Error handling

## 🚀 Usage

### Normal mode

```bash
./file_organizer.sh ~/Downloads
